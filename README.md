# Aim Trainer

Jednoduchý webový projekt herního rozhraní (Aim Trainer) vytvořený ve frameworku Next.js s využitím Reactu a Tailwind CSS.

## Spuštění projektu

1. **Instalace závislostí:**
   ```bash
   npm install
   ```

2. **Spuštění vývojového serveru:**
   ```bash
   npm run dev
   ```

3. Otevřete v prohlížeči adresu: [http://localhost:3000](http://localhost:3000)

## Větve projektu (Branches)

* `main` – hlavní produkční větev projektu
* `dev` – vývojová větev pro práci na nových funkcích
* `test` – testovací větev pro ověřování funkčnosti
